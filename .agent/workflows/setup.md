# Nexora First-Run Setup

Ask one question at a time. Do not overwhelm the user with a long form.

1. Identify the coding environment: Kilo Code, Google Antigravity, GitHub Copilot, or another tool.
2. Ask whether the task is a new product, an existing project, or frontend-only for an existing backend.
3. Inspect the repository before asking for information that can be discovered locally.
4. Explain each relevant skill and ask whether it should be enabled, ask-first, or disabled. Do not ask about irrelevant skills.
5. Ask autonomy preference: Ask-first, Guided (default), or Autopilot-local.
6. For UI work, ask for product idea/audience only if not inferable; analyze each attached reference separately.
7. For existing backend, document protected paths and API contracts before editing.
8. Save approved preferences in `.agent/config/skills.json`.
9. Verify configuration and provide commands/workflows available in the current IDE.
10. Never claim a skill is loaded unless the current IDE actually supports and loads it.
