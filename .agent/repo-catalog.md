# Optional Third-Party Repositories

These were suggested as possible integrations. They are not vendored into Nexora, and no code is automatically installed from them. Before using any repository, inspect its current README, license, dependencies, setup, security posture and compatibility with the chosen IDE.

1. REA — https://github.com/morluto/rea — reverse engineering exploration
2. Ponytail — https://github.com/DietrichGebert/ponytail — coding workflow exploration
3. Hallmark — https://github.com/nutlope/hallmark — creative UI/design exploration
4. Humanizer — https://github.com/blader/humanizer — writing style exploration
5. Onyx — https://github.com/onyx-dot-app/onyx — self-hosted knowledge assistant
6. Impeccable — https://github.com/pbakaus/impeccable — UI polish/design skills
7. UI UX Pro Max — https://github.com/nextlevelbuilder/ui-ux-pro-max-skill — UI/UX design skill
8. Last 30 Days — https://github.com/mvanhorn/last30days-skill — recent discussion research
9. Scrapling — https://github.com/D4Vinci/Scrapling — Python web-data extraction
10. Diagram Design — https://github.com/cathrynlavery/diagram-design — HTML/SVG technical diagrams

Verify repository existence, current contents and licenses before integration. Names and descriptions above are intended-use notes, not a security or compatibility audit.
