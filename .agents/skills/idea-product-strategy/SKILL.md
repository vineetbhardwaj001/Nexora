# Idea to Product Plan

Clarify target users, problem, value proposition, assumptions, alternatives and success metrics. Separate MVP from later features and non-goals. Define roles, user journeys, page/module inventory, acceptance criteria, architecture options, risks, milestones and validation plan. If UI references are provided, analyze each separately using the UX/UI skill. Ask one question at a time when a blocking choice is missing. Do not implement unless asked.
