# UX/UI Design Skill

Analyze every supplied reference image separately before comparing them. For each image record its palette, typography, layout, components, imagery/texture, interaction hypotheses, responsive risks, accessibility, reusable principles and brand-specific elements. Mark inferred values and estimated colors/fonts clearly.

Then:
1. Understand the product, audience, main task and conversion goal.
2. Compare style families only after separate analyses.
3. Recommend one coherent design direction based on product fit.
4. Define color/type/spacing/grid/radius/border/shadow tokens.
5. Plan page hierarchy, reusable components, states, responsive behavior and accessibility.
6. Ask before major redesign unless the user explicitly requested implementation.
7. Verify keyboard access, focus, contrast, reduced motion, mobile layouts and loading/empty/error/success states.

Avoid generic template-looking UI and decorative clutter. Do not copy logos or proprietary artwork blindly. Static screenshots cannot prove animations or interactions.
