# Nexora Shared Rules

Read `AGENTS.md`, `.agent/CORE.md`, `docs/COMMANDS.md`, and the relevant `.agents/skills/*/SKILL.md`. Use `docs/ROADMAP.md` to distinguish merged features from open-PR proposals. Keep Persona Lab counts distinct: 100 profiles != 100 real users != 100 LLM agents != 100 simultaneous browsers. Inspect before editing. Analyze each UI reference separately. When building a frontend for an existing backend, treat backend paths as read-only, use actual API contracts, and verify the final diff. Ask before destructive or production actions. Run relevant checks and report actual results.
