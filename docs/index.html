05 GOOD TO KNOW

Curious before you try it?

Is Nexora ready to work with every coding tool?

Not yet. Nexora currently provides a starter kit, CLI, reusable instructions, and tool-specific configuration files. Adapters must be tested with each target tool and version before being treated as supported.

Do I need to publish or install it from npm?

No. The current recommended path is to clone the repository and test it locally. npm publishing is not part of the current workflow.

Does Nexora guarantee free AI models?

No. Strict free-only routing is a roadmap item. Provider pricing, quotas, and fallback behavior must be verified before a zero-cost policy can be promised.

How can I help improve the project?

Review the repository, run its checks, open an issue with a concrete use case, improve documentation, or propose a focused change.
